## 16-Phase Pipeline

V6.5 executes a comprehensive 16-phase trading pipeline:

### Phase 0: Exit Management (Runs FIRST)
- Checks all open positions for TP/SL/time exits
- Triggers learning on any positions closed
- Runs every cycle regardless of new signals

### Phase 1: Market Scanning
- Scans 3-10 instruments for opportunities
- Filters by spread (< 0.5 pips) and volume (> 100)
- Scores opportunities by volume and spread quality
- Returns top 5 opportunities

### Phase 2: AI & Regime Detection
- Ensemble prediction using multiple ML models
- HMM regime detection (TRENDING, BREAKOUT, RANGING, VOLATILE)
- Meta-learning adjustment based on market conditions
- Asset-class specialized ensembles

### Phase 3: Sentiment Analysis (V6.5 NEW)
- News sentiment scoring
- Social media sentiment
- Order flow sentiment
- Combined sentiment score with confidence

### Phase 4: News Strategy (V6.5 NEW)
- Economic event awareness
- News-based strategy switching
- Event impact prediction
- Avoids trading during high-impact news

### Phase 5: Order Flow (V6.5 NEW)
- Institutional activity detection
- Large order detection
- Volume analysis
- Smart money flow tracking

### Phase 6: Pattern Recognition (V6.5 NEW)
- Deep learning candlestick patterns
- Pattern confidence scoring
- Historical pattern matching
- Pattern failure detection

### Phase 7: Multi-Timeframe (V6.5 NEW)
- Timeframe confluence analysis
- Higher timeframe trend alignment
- Lower timeframe entry optimization
- Multi-TF confidence scoring

### Phase 8: Signal Generation (Combined)

  - Regime: 10%

### Phase 9: Risk Management

### Phase 11: Adaptive Take-Profit (V6.5 NEW)

### Phase 12: Diversification Check (V6.5 NEW)

## Lot Size Calculations

### Formula
```
Lot Size = Risk Amount / (Stop Loss Pips × Pip Value per Lot)
```

### For $100 Account (0.01 lots typical)
```python
# Risk amount: $1.00 (1% of $100)
# Stop loss: 20 pips
# Pip value for 0.01 lots: $0.10

lot_size = 1.00 / (20 × 0.10) = 0.50 lots

# But capped at 0.05 for $100 account
lot_size = min(0.50, 0.05) = 0.05 lots
```

### Practical Example
```
Trade: BUY EURUSD
Entry Price: 1.1000
Stop Loss: 1.0980 (20 pips)
Take Profit: 1.1060 (60 pips, 3:1 R:R)

Risk Amount: $1.00
Lot Size: 0.01 lots
Pip Value: $0.10 per pip

If TP hit: 60 pips × $0.10 = $6.00 profit
If SL hit: 20 pips × $0.10 = $2.00 loss
```

## Risk Management Rules

### Circuit Breakers
1. **Daily Loss Limit:** 2% ($2 for $100 account)
2. **Weekly Loss Limit:** 5% ($5 for $100 account)
3. **Monthly Loss Limit:** 10% ($10 for $100 account)
4. **Max Drawdown:** 15% ($15 for $100 account)

### Position Limits
1. **Max Open Positions:** 5
2. **Max Daily Trades:** 10 (3 recommended for $100)
3. **Max Correlation:** 0.7 (reduces size for correlated pairs)
4. **Min Risk-Reward:** 2.0 (minimum 2:1 R:R)

### Trailing Stop Rules
- **5 pips profit:** Move stop to breakeven + 1 pip
- **10 pips profit:** Trail 5 pips behind price
- **20 pips profit:** Trail 10 pips behind price
- **50 pips profit:** Trail 15 pips behind price
- **100+ pips profit:** Trail 20 pips behind price

### Partial Close Rules
- **TP1 (33%):** Close 1/3 of position
- **TP2 (66%):** Close another 1/3
- **TP3 (100%):** Close remaining position
- **Move SL to breakeven** after TP1 hit

## Monitoring and Adjustment

### Key Metrics to Monitor
1. **Win Rate:** Target 55%+ for V6.5
2. **Profit Factor:** Target 1.5+ (wins/losses)
3. **Max Drawdown:** Keep below 10%
4. **Sharpe Ratio:** Target 1.0+
5. **Daily P&L:** Track against targets

### Monitoring Commands
```bash
# Check V6.5 status
python manage.py shell -c "from ml.v65_orchestrator import get_v65_orchestrator; o = get_v65_orchestrator(); o.initialize(); print(o.component_count)"

# Check backup system status
python manage.py shell -c "from ml.enhancements.backup_manager import get_backup_manager; bm = get_backup_manager(); print(bm.get_status())"

# Run virtual simulation
powershell -File scripts/virtual-100-sim.ps1 -InitialBalance 100 -SimulationDays 30
```

### Adjustment Guidelines

#### If Win Rate Drops Below 50%:
1. Increase minimum confidence threshold
2. Reduce position size
3. Check market regime (avoid ranging markets)
4. Review recent trade patterns

#### If Drawdown Exceeds 10%:
1. Reduce risk per trade to 0.5%
2. Max daily trades to 1
3. Tighten stop losses
4. Avoid new positions until recovery

#### If Profit Factor Drops Below 1.2:
1. Review take-profit levels
2. Adjust risk-reward ratio
3. Check for correlated losses
4. Consider pausing trading

### Auto-Optimization
V6.5 includes a self-optimizing system that:
- Runs genetic algorithm optimization every 24 hours
- Adjusts parameters based on recent performance
- Updates confidence thresholds dynamically
- Modifies position sizing based on drawdown

### 2. Run Auto-Configuration
```bash
powershell -File scripts/configure-v65.ps1
```

### 3. Start Trading
```bash

# Start Celery beat (scheduler)
celery -A config beat -l info

# Or use the start script
powershell -File scripts/start-local.ps1
```

### 4. Monitor Performance
```bash
# Check logs
tail -f django_out.log

# Run simulation
powershell -File scripts/virtual-100-sim.ps1 -Verbose
```
