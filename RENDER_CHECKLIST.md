# Render Deployment Checklist — DutchKEM Trading AI

## Prerequisites
- [x] `render.yaml` uses `runtime: docker` with correct `dockerfilePath: Dockerfile`
- [x] `Dockerfile` base image is `python:3.12-slim`
- [x] `backend/requirements.txt` includes all required packages
- [x] Health check path is `/health/`
- [x] No old fortress/SaaS references in config files

## Deployment Steps

### 1. GitHub Setup
- [ ] Push repo to `https://github.com/dutchkemsystems/dutchkem-trading-ai.git`

### 2. Render Account
- [ ] Create Render account at https://dashboard.render.com

### 3. Deploy from Blueprint (recommended)
- [ ] Go to **New > Blueprint** → connect your GitHub repo
- [ ] Render will detect `render.yaml` and auto-create the web service + PostgreSQL database

### 4. OR Manual Web Service Setup
- [ ] New → **Web Service** → connect repo
- [ ] **Runtime**: Python
- [ ] **Build Command**: `pip install -r backend/requirements.txt`
- [ ] **Start Command**: `cd backend && python manage.py migrate --no-input && python manage.py collectstatic --no-input && gunicorn config.wsgi:application --bind 0.0.0.0:$PORT --workers 4 --timeout 120`

### 5. Environment Variables (auto-set via render.yaml or add manually)
- [ ] `SECRET_KEY` — auto-generated by Render
- [ ] `DEBUG=0`
- [ ] `USE_SQLITE=0`
- [ ] `DJANGO_SETTINGS_MODULE=config.settings_production`

### 6. Database
- [ ] Create PostgreSQL instance (`dutchkem-db`)
- [ ] `DATABASE_URL` — linked from database connection string

### 7. Redis
- [ ] Create Redis instance on Render
- [ ] `REDIS_URL` — copy internal Redis URL
- [ ] `CELERY_BROKER_URL` — set to same Redis URL

### 8. MT5 Bridge
- [ ] `MT5_HOST` — your bridge domain/IP
- [ ] `MT5_PORT=443`
- [ ] `MT5_WS_PORT=443`

### 9. Post-Deploy Verification
- [ ] Visit `https://dutchkem-trading-ai.onrender.com/health/` → returns 200
- [ ] Visit `https://dutchkem-trading-ai.onrender.com/api/docs/` → Swagger UI loads
- [ ] Create superuser via Render Shell: `python manage.py createsuperuser`
- [ ] Test API endpoints with Swagger

### 10. Frontend CORS
- [ ] Ensure `CORS_ALLOWED_ORIGINS` includes your frontend URL
- [ ] Ensure `ALLOWED_HOSTS` includes your backend URL
